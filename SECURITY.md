# Reporting a security vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/maweis1981/doubo-community/security/advisories/new) to send security-sensitive details to the maintainers.

Do not publish credentials, access tokens, private playlist links or exploit details in a public Issue or Discussion. Include the affected platform/version and a minimal, redacted reproduction in your private report.

For ordinary setup questions, use [Discussions](https://github.com/maweis1981/doubo-community/discussions). For non-sensitive, reproducible bugs, use the [issue form](https://github.com/maweis1981/doubo-community/issues/new/choose).
