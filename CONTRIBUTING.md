# Sharing useful feedback

Search existing Discussions and Issues before starting a new topic.

For a question, describe what you want to do, your platform and your app version in Discussions. Include enough context for another user to understand the answer.

For a bug, use the issue form and provide a short sequence of steps, the expected result and the actual result. Report one problem per issue. For a feature request, explain the problem it would solve.

Redact screenshots and logs. Do not upload private playlists, credentials, tokens, payment information or personal contact details. A public example should use a harmless test stream or sample data.

Public documentation should focus on product behavior, compatibility and verified answers. Keep internal plans, operational approvals, private repository references and non-public analytics outside this repository.
